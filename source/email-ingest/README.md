# Email-Ingested Deployment Materials

These files were recovered from project deployment correspondence in the connected Gmail account and are included as a source snapshot for the broader Sovereign/Aegentix deployment context.

The materials include a Cybercore deployment pack and an Agents of Chaos/Mixture-of-Experts guardrail design. They are not presented as proof that EOC custody, treasury, or exchange-listing controls are deployed. They require code review, dependency review, and environment-specific testing before execution.

## Exclusions

Recovery codes, private keys, credentials, personal correspondence, and unrelated attachments were intentionally excluded. No email body containing credentials is copied into this repository. Google Drive was not ingested because no Drive connector is connected in this session.

## Provenance

The source material came from project deployment correspondence dated September 2026. The attachment files are retained with descriptive names; mailbox addresses and recovery-code content are not reproduced here.
