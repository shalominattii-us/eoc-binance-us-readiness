# Multi-Account Google Drive Deployment Ingest

This directory contains unique, text-based deployment artifacts identified in the authorized Google Workspace Drive review. The source set includes the Sovereign OS specification, master inventory, Cybercore and deployment scripts, an LLM bridge/configuration component, and the Sovereign Claw Overwatch protocol.

The files were selected from shared project material associated with the authorized Google Workspace accounts. Duplicate artifacts were not copied repeatedly.

## Safety boundary

Credential-like files, `.env` files, recovery codes, private keys, executables, DLLs, archives, tax/payroll documents, unrelated personal records, and unreviewed binary artifacts were excluded. A basic credential-pattern scan was run before publication.

These scripts are untrusted source material. They must not be executed in production without dependency review, sandbox testing, secret scanning, and explicit deployment approval. Their presence does not establish production deployment, legal status, custody, reserves, or security assurance.
