# Security Policy

Do not submit private keys, seed phrases, wallet backups, API secrets, credentials, or personally identifying information through GitHub issues or pull requests.

The included verifier is read-only. It cannot sign, mint, transfer, freeze, alter trust lines, or change custody. The source snapshots include design and policy artifacts that require independent review before any production use.

If a security issue is found, open a private security report through GitHub or contact the repository owner through a verified channel. Include the affected path, reproduction steps, and impact without including secrets.
